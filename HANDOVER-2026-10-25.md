## 1. The project in one paragraph

Cozy Acres is a mobile-first 3D farming and village builder (Three.js + TypeScript + Vite). It runs in the browser as an
offline PWA and, from 1.32.0, as a Capacitor Android app with the game inside it. Optional online play (friends, gifts,
market, leaderboards, visits, co-op, home coffee visits, cloud saves with Google sign-in) runs on Supabase. Owner: Josh
Makes Games (Australia). Repo `JLA92-bit/Cozy-Farm`; pushing `main` deploys the website and web game through GitHub
Pages. Game: https://cozyacres.joshmakesgames.app/play/ . Dashboard: `/admin/` (`ADMIN.md`).

## 4. Risky or untested

1. **Farms do not move from the old TWA to the new app by themselves.** The TWA kept its save in Chrome; the app has
   its own storage. Signed-in players get their cloud farm back by signing in in the app; players who never signed in
   start fresh in the app (their farm is still on the website in Chrome). The owner was told to ask testers to sign in
   first. A first-start "Played before? Sign in to bring your farm across" prompt was offered, not built.
2. **No notifications in the app** (web push does not work in the WebView; Settings says they are coming). Needs
   Firebase Cloud Messaging for Android and APNs for iPhone, plus a change to `supabase/functions/send-push`.
3. **The Android workflow has not run on GitHub yet** at the time of writing (only built locally). Check its first run.
4. **Real-phone testing** is still thin (rule 9: Low, Medium, High).

## 5. The iPhone app: what the Mac session does

Work on the Mac, in a clone of this repo, on a branch (for example `ios-app`). Pull first, push only after "yes push".

1. **Add Capacitor iOS:** `npm install @capacitor/ios` (same major as `@capacitor/core`, 8.x), `npx cap add ios`,
   commit `ios/` (Capacitor's own `.gitignore` there leaves out the copied web files). Bundle ID
   `app.joshmakesgames.cozyacres`, display name Cozy Acres, iPhone only at first (no iPad screenshots), portrait and
   landscape as the game supports. Add the URL scheme `app.joshmakesgames.cozyacres` (deep link for sign-in) to
   `Info.plist`, `ITSAppUsesNonExemptEncryption` false. Icons and splash from `public/icons` (extend
   `scripts/app-icons.py`). Check safe areas on a notched iPhone (`--safe-area-inset-*` CSS vars, `src/ui/styles.css`).
2. **Make `isNative()` code paths platform-aware** where it matters: `PLAY_URL` is Android only (an App Store URL for
   iPhone once the app exists); the newer-save Update button and anything that says "Play Store".
3. **Sign in with Apple** (App Store guideline 4.8, because Google sign-in is offered): Supabase Apple provider,
   `signInWithOAuth({ provider: 'apple' })` through the same `toGoogle`-style browser + deep link flow in
   `SupabaseBackend.ts` (rename the helper), a button next to Google in Settings. Owner needs to create a Services ID
   and key in the Apple Developer account and turn on Apple in Supabase > Authentication > Providers.
4. **Report and block players** (guideline 1.2, free text: gift notes, farm and player names, signs). Server: a new
   `-- ===== reports and blocks =====` section in `supabase/schema.sql` (tables referencing `profiles` with cascade,
   `report_player`, `block_player`, `unblock_player`, blocked players filtered out of gifts, visits, market and friend
   lists), a dashboard Reports page. Test on a local Postgres 16 first (`HANDOVER-2026-10-21.md` section 5). Remind the
   owner to run the whole `schema.sql` and `notify pgrst, 'reload schema';`. Update the privacy page and
   `store/data-safety.md`.
5. **Build and upload from the Mac:** `npm run build:app` (extend the script so it syncs iOS too, e.g.
   `cap sync`), then Xcode (Product > Archive > Distribute App > App Store Connect) or `xcodebuild` + `xcrun altool`.
   TestFlight on the owner's iPhone first. Write the steps into a new `ios/README.md`.
6. **App Store Connect (owner, with help):** Free Apps agreement, create the app, App Privacy answers (from
   `store/data-safety.md`), age rating 13+, export compliance (HTTPS only), EU trader status or leave EU out at first,
   privacy policy and support URLs, 6.9-inch iPhone screenshots (1320 x 2868).

Apple has no tester-count rule; review is usually 1-2 days. Game updates for iPhone players need new builds, like
Android.

## 7. Mac setup (one time)

1. Terminal: `xcode-select --install` (git). Install Node.js LTS from nodejs.org, Xcode from the Mac App Store, and
   GitHub Desktop (sign in with the GitHub account that owns the repo).
2. `cd ~/Documents && git clone https://github.com/JLA92-bit/Cozy-Farm.git && cd Cozy-Farm && npm install`
3. Claude Desktop app (choose the `Cozy-Farm` folder) or `claude` in that folder in Terminal.
4. Xcode > Settings > Accounts: add the Apple ID once the developer membership is active.

Two sessions, one repo: each session starts with `git pull`, pushes after "yes push", and the two never change the
same files at the same time. The Mac session owns `ios/` and iPhone builds.
